# In拼图·何罗鱼 v0.2.0 发行说明

> 发布日期：2026-11-04 · 平台：Windows x64 · 许可证：MIT

把多张图片拼成一张成图：导入 → 选模板或自由排版 → 调整 → 导出 PNG / JPEG。全部处理在本机完成，运行期不发起任何网络请求。

**性能优先的默认配置**
新增设置面板：交互动画、装饰性阴影默认关闭，面向老旧机型与远程桌面。两项都不影响导出画质；系统开启「减少动效」时应用内即使打开也会被强制关闭。

**内存与稳定性**
图片移出画布后立即释放解码位图（单张约 16 MB）；导出增加双重防重入；`read_image_png` 的缩放参数夹到 16~8192，挡住异常参数引发的一次性超大分配。

**安全**
启用 CSP：脚本与连接仅限本地，`object-src`、`frame-ancestors`、`base-uri` 全部收紧。构建产物无遥测、无 updater，由测试守卫。

## 功能

| 模块 | 能力 |
| --- | --- |
| 导入 | 文件对话框、窗口拖放、剪贴板；PNG / JPEG / WebP / BMP；EXIF 方向校正；重复导入询问 |
| 画布 | 5%~800% 缩放、空格平移、八向控制点、多选；四类背景；越界提示 |
| 排版 | 20 个模板；空槽位编号，双击资源库按序号填充；拖入可填空、替换或自由放置 |
| 图像 | 非破坏性裁剪、透明度、边框、圆角，均可撤销 |
| 图层 | 列表排序、六向对齐、等距分布、边与中线吸附（`Alt` 临时关闭） |
| 导出 | PNG / JPEG；条带渲染控制内存；进度与取消；原子落盘 |

完整功能与快捷键见仓库 `README.md` 与 `docs/SHORTCUTS.md`。

## 修复

- **导出失败**：`asset.localhost` 跨源污染 canvas 导致 `toBlob` 报 `Tainted canvases may not be exported`，改用 `blob:` 同源位图，顺带修好大画布导出分辨率不足。
- **空槽位填不进**：占位判定方向反了，邻格图片放大后会把空槽误判为已占用。
- **双击放入时灵时不灵**：全屏预览抢走双击第二下，改为单击延迟 240ms。
- **模板实例压到邻格**：单元格容器 `clip`，超出部分不再压到相邻格。

## 性能（开发机实测）

| 场景 | 结果 |
| --- | --- |
| 画布 50 实例 | 每帧管线 p95 **1.2 ms**（适应画布）/ **1.3 ms**（100%），约占 60Hz 预算 7% |
| 导入 50 张 3000×2000 | 50/50 成功，**1.29 s** |
| 导出 2400×20000 PNG | **0.70 s**，峰值内存 316 MB |

数字用于判断量级，不代表所有机型。

## 安装

```
pintu-Windows10/11-amd-x86_64-setup.exe    2.28 MiB
```

- 要求 Windows x64 与 WebView2 Runtime（Windows 11 已内置；Win10 需自行确认）。
- 安装包**未做代码签名**，首次运行会出现 SmartScreen 提示，选「更多信息 → 仍要运行」。
- 构建校验：前端 263 项、Rust 27 项用例通过，typecheck 与 lint 无告警。
- 卸载不删除你导出的图片；偏好存于 `%APPDATA%\com.everettlineo.pintu`，缩略图缓存存于 `%LOCALAPPDATA%\com.everettlineo.pintu`。

## 已知限制

- 仅支持 Windows。
- 不支持 HEIC / HEIF，会明确报错而非静默失败。
- 单边导出上限 20 000 px，RGBA 缓冲上限 512 MB。
- 文档不落盘，没有自动保存与多文档；关闭窗口即清空，撤销上限 100 步。
- 模板固定 20 个，暂不支持保存自定义模板。
