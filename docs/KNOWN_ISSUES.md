## KI-01（已关闭）`image` 默认 feature 全开

- **现象**：编译拉入 tiff / exr / avif / tga / ico / hdr 等未使用编解码器，依赖 126 个、构建 60s
- **处理**：改为 `default-features = false`，仅启 png/jpeg/webp/bmp
- **结果**：依赖 34 个、构建 21.76s、四格式解码行为一致（TR-02）
- **状态**：已关闭（2026-10-27）

## KI-02 低 `fast_image_resize` 尚未启用

- **影响**：无功能影响，仅未验证其重采样耗时
- **计划**：T0.9 导出原型中启用并计时
- **影响发布**：否

## KI-03 探测工程占用磁盘

- **位置**：`C:\TEMPs\_probe_img`、`C:\TEMPs\_probe_tauri`
- **影响**：含两套 cargo target，合计约 3~4 GB
- **规避**：P1 正式工程建立后删除
- **影响发布**：否

## KI-04 基准测量的语义陷阱

- **现象**：`layer.batchDraw()` 为延迟绘制，其返回耗时只是"入队耗时"，不是光栅化耗时
- **风险**：若据此推算 FPS 会得出荒谬结论（如 25000 fps）
- **规避**：性能数字一律以帧间隔与 Chrome Tracing 采样为准
- **已固化为**：`task.md` T3.7 的实现要求
- **影响发布**：否（但影响性能结论的可信度，故记录）

## KI-05 HEIC 拒绝的验证深度不足

- **现象**：仅用构造的 `ftyp` 签名文件验证"不崩溃"，未用真实 HEIC 照片
- **影响**：无法证伪"真实 HEIC 文件可能触发更深层解析错误"
- **规避**：v1 明确不支持该格式，仅需错误提示正确
- **计划**：若后续用户反馈，补真实样本复测
- **影响发布**：否

## KI-06 未覆盖的图片变体

- **范围**：CMYK JPEG、16 位 PNG、渐进式 JPEG、有损 WebP、带 ICC 的图片
- **影响**：可能出现解码失败或偏色
- **计划**：并入 T12.2（异常输入）与 T10.10（色彩配置）
- **影响发布**：**待定** —— 若 T12.2 发现解码崩溃，须升级为阻断性缺陷处理
