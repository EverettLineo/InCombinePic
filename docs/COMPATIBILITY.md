## 2. 构建与打包（已实测）

| 项 | 结果 | 状态 |
| --- | --- | --- |
| Tauri 2 空模板 release 构建 | 4 分 07 秒 | 已实测 |
| 可执行文件 | 产出 `app.exe` | 已实测 |
| MSI 安装包 | 2.04 MiB，`wix314` 工具链 | 已实测 |
| NSIS 安装包 | 1.39 MiB，`nsis-3.13` 工具链 | 已实测 |

> **边界说明（重要）**：Tauri 首次打包会从 GitHub 下载 WiX / NSIS 工具链，**构建机需联网**。这不影响安装后运行的离线能力。不得对外表述为"构建过程完全离线"。

## 4. 目标平台支持范围

| 平台 | 状态 | 说明 |
| --- | --- | --- |
| Windows 11 24H2/25H2（build 26300） | **已实测** | 本机即验证环境 |
| Windows 10 22H2 x64 | **理论支持，未测试** | WebView2 与 Rust msvc 目标均支持；需在真实 Win10 机器验证后升级为"已实测" |
| Windows 10 早期版本 | 理论支持，未测试 | 受 WebView2 版本与 UCRT 影响 |
| Windows 8.1 及以下 | **不支持** | Tauri 2 不支持 |
| Windows ARM64 | 理论支持，未测试 | 需交叉编译或原生环境验证 |
| 32 位 Windows | **不支持** | 无对应目标 |
| macOS / Linux | 不在 v1 范围 | 架构未做跨平台假设，但未验证 |
