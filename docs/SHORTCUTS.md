# 快捷键总表（T11.1）

> 实现位置：`src/app/useAppShortcuts.ts`（全局唯一入口）。
> 分散到多个监听器会让"Esc 先关弹窗还是先取消选择"变成监听器注册顺序问题，因此集中在一处。

## 全局

| 快捷键 | 行为 | 备注 |
| --- | --- | --- |
| `Ctrl+Z` | 撤销 | 连续拖动/缩放只回退一步（`mergeKey` 合并） |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 | 两个都支持，照顾不同习惯 |
| `Ctrl+A` | 全选画布实例 | 输入框内是"选中文本"，不抢 |
| `Ctrl+O` | 导入图片 | 左栏常驻资源库，无需切换面板 |
| `Ctrl+E` | 打开导出面板 | |
| `Delete` / `Backspace` | 删除选中实例 | 可撤销；只删实例，不删资源库条目 |
| `Esc` | 逐级退让：关闭弹窗 → 取消选择 | 导出进行中不关面板 |

## 画布

| 快捷键 | 行为 |
| --- | --- |
| 滚轮 | 以指针为锚缩放 |
| `Space` + 拖动 | 平移视图 |
| 拖动控制点 | 缩放选中对象（八向） |
| 按住 `Alt` 拖动 | 临时关闭智能吸附，用于精细摆放（D-04） |
| 拖动图片 | 移动选中集合（多选时整体移动） |

## 弹窗内

| 位置 | 快捷键 | 行为 |
| --- | --- | --- |
| 裁剪浮层 | `Esc` | 取消并丢弃未应用的裁剪 |
| 选图弹窗 | `Esc` | 关闭，不放入 |
| 导出面板 | `Esc` | 关闭（导出进行中除外） |
| 数值输入框 | `Enter` | 提交 |
| 数值输入框 | `Esc` | 回滚到原值并失焦 |

## 焦点优先级（T11.2）

所有全局快捷键在处理前统一判断焦点：`input` / `textarea` / `contenteditable` 内**一律不接管**。

理由：输入框里 `Ctrl+Z` 应当是文本撤销、`Ctrl+A` 应当是选中文本、`Esc` 应当是回滚本次输入。
若不判断焦点，用户在数值框里按 `Ctrl+A` 会把整个画布选中——这类问题在真实使用中极招人烦，但在自测时几乎不会碰到（因为自测时手都在画布上）。

## 未实现的快捷键（v1 范围外）

| 快捷键 | 说明 |
| --- | --- |
| `Ctrl+S` | 不做"保存工程"：v1 没有工程文件，导出即落盘 |
| `Ctrl+Shift+S` | 同上 |

| 框选（拖拽空白） | 基线明确 v1 不做 marquee selection |
