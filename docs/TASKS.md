# 任务清单索引

**任务详表不在本文件，唯一真源是项目根目录 [`../task.md`](../task.md)。**

保留本文件是为了满足基线 §3 阶段 B 要求的 `docs/TASKS.md` 约定，同时避免两处维护导致状态不一致。

## 为什么不在此复制任务表

两份任务表必然出现状态漂移，而状态漂移会直接导致"以为已完成"的误判。因此约定：

- **状态、依赖、验收标准** → 只维护 `task.md`
- **本文件** → 只保留阶段总览与统计，供快速浏览
